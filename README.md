# 🌍 AI Multilingual Translator

An AI-powered multilingual translation application built with Streamlit.

## Features

- Text → Text Translation
- Voice → Text
- Text → Speech
- Voice → Voice Translation
- Image Translation (OCR)
- Document Translation
- Language Detection
- Translation History

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
streamlit run app.py
```
